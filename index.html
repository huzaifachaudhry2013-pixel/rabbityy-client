Features

Everything you need to play

A clean launcher experience with customization, version selection, useful settings, and live launch progress.

⚡

Fast launching

Select your Minecraft version and launch from one simple, responsive interface.

🎨

Custom appearance

Use custom backgrounds, adjustable blur and darkness, particles, and multiple accent themes.

⚙

Advanced settings

Configure RAM, game resolution, fullscreen mode, Java path, game directory, and JVM arguments.

◇

Version selection

Play supported Minecraft releases and optionally enable development snapshots.

▣

Live console

View launch progress and game logs directly from the launcher when troubleshooting.

♢

More coming later

Mod support and instance management are planned for future versions of Rabbityy Client.
